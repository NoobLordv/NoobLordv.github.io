# Quequenlandia

Portal nacional de Quequenlandia.

## Publicación
Este repositorio es el sitio de usuario de GitHub Pages: https://nooblordv.github.io/

La página principal está en `index.html` y utiliza `bandera.svg` como emblema.

## Contenido
- Presentación nacional
- Bandera y símbolos
- Identidad e instituciones
- Sección cultural para el Himno de Queque

**Nota:** el reproductor está preparado para `himno-del-queque.mp3`, pero el archivo de audio todavía debe incorporarse al repositorio para que pueda reproducirse en la web.
